# Perpus11 - Sistem Manajemen Perpustakaan

<p align="center">
  <img src="https://raw.githubusercontent.com/laravel/art/master/logo-lockup/5%20SVG/2%20CMYK/1%20Full%20Color/laravel-logolockup-cmyk-red.svg" width="200" alt="Laravel Logo">
  <img src="https://filamentphp.com/assets/filament-logo.svg" width="200" alt="Filament Logo">
</p>

Sistem manajemen perpustakaan modern berbasis web yang dibangun dengan Laravel 12 dan Filament 4. Aplikasi ini menyediakan fitur lengkap untuk mengelola peminjaman buku, anggota, katalog, dan transaksi perpustakaan dengan antarmuka admin yang intuitif.
